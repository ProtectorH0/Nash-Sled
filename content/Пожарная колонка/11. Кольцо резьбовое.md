# Общие сведения

***Резьбовое кольцо пожарной колонки*** — это деталь в нижней части корпуса колонки с внутренней специальной резьбой. Предназначено для навинчивания пожарной колонки на подземный пожарный гидрант.
Это ключевой элемент соединения «колонка–гидрант»: без него невозможно надёжно зафиксировать колонку на гидранте и обеспечить подачу воды.

# ТТХ
| Параметр               | Значение                                                            |
| ---------------------- | ------------------------------------------------------------------- |
| *Условный проход (Ду)* | *125 мм (под стандартный гидрант).*                                 |
| *Шаг резьбы*           | *4–6 мм (трапецеидальный профиль).*                                 |
| *Число витков*         | *6–8 витков*                                                        |
| *Твёрдость материала*  | *не менее 180 HB*                                                   |
| *Ресурс*               | не менее 300 циклов «навинчивание–снятие» без потери герметичности. |
# Предназначения

1. ***Фиксация колонки на гидранте.*** Обеспечивает прочное соединение с резьбовой частью гидранта.
2. ***Герметизация стыка.*** Совместно с уплотнительным кольцом создаёт водонепроницаемое соединение.
3. ***Передача усилия при монтаже.*** Принимает на себя крутящий момент при навинчивании колонки (до 45 кгс).
4. ***Центрирование колонки.*** Помогает точно совместить квадратный хвостовик центрального ключа с торцом штока гидранта.
5. ***Обеспечение долговечности соединения.*** Специальная резьба снижает износ при многократном монтаже/демонтаже.
