# Общие сведения

***Верхний корпус*** — верхняя разъёмная часть литого корпуса колонки.  Именно в верхнем корпусе сосредоточена вся «управляющая» часть колонки: выходные патрубки с запорными устройствами и узел центрального торцевого ключа.

# ТТХ (в составе колонки КПА) 

Как и нижний, верхний корпус отдельно нормативными характеристиками не нормируется — его параметры проверяются на колонке в сборе:

| **Параметр**                                     | **Значение**                                   |
| :----------------------------------------------- | :--------------------------------------------- |
| *Габариты колонки (длина × ширина × высота)* | *не более 430 × 190 × 1090 мм*                 |
| *Герметичность соединений*                   | *1,2 МПа, без капель на наружных поверхностях* |
| *Коэффициент гидравлического сопротивления*  | *не более 10*                                  |
| *Масса колонки*                              | *не более 16 кг (у КПА из алюминия — ~15 кг)*  |
| *Присоединительная резьба патрубков*         | *муфтовая головка ГР-80*                       |
| *Прочность (опрессовка)*                     | *1,5 МПа*                                      |
| *Рабочее давление*                           | *не более 1,0 МПа (10 кгс/см²)*                |
| *Усилие открывания/закрывания вентилей*      | *не более 450 Н (45 кгс)*                      |
| *Условный проход: входного патрубка*         | *125 мм*                                       |
| *Условный проход: выходного патрубка*        | *<br>80 мм (головки ГМ-80)*                    |
| *Число выходных патрубков*                   | *не менее 2*                                   |

# Предназначение
Верхний корпус выполняет 4 функции:

1. ***Подача воды.*** К корпусу крепятся два выходных патрубка условным проходом 80 мм с муфтовыми соединительными головками (ГР-80), к которым подключают пожарные рукава, стволы или колонку-водослив для заправки автоцистерн. 
2. ***Регулирование потока.*** В патрубках установлены запорные вентили (клапаны тарельчатого типа со шпинделем), которые открываются и закрываются маховиками-рукоятками по обе стороны корпуса. Это позволяет управлять подачей по каждому патрубку независимо. 
3. ***Привод клапана гидранта.*** Через верхний корпус проходит полый центральный (торцевой) ключ: сверху он заканчивается рукояткой-черенком, снизу — квадратной головкой под квадрат штока гидранта (25 мм). Вращение ключа против часовой стрелки открывает шаровый клапан гидранта; верхняя часть ключа проходит именно через полость верхнего корпуса. 
4. ***Передача воды из нижнего корпуса в патрубки.*** Внутренняя полость верхнего корпуса объединяет поток от входного прохода 125 мм с двумя выходными 80 мм.
