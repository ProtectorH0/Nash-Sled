# Общие сведения

***Центральный (торцевой) ключ*** — это устройство Т-образного вида с квадратной головкой на нижнем конце и рукоятками в верхней части, которое проходит насквозь через колонку, имеет в нижней части квадрат со стороной (25 ± 0,5) мм. 
Термин «торцевой» ключ закрепился и за отдельной запасной частью — обычно это труба с квадратной головкой и Т-образной поперечиной.

# ТТХ

Нормируемые параметры ключа в составе колонки по ГОСТ Р 53250-2009: 

| Параметр                                   | Значение                                    |
| ------------------------------------------ | ------------------------------------------- |
| Форма                                      | Т-образная, проходит насквозь через колонку |
| Квадрат головки                            | сторона 25 ± 0,5 мм                         |
| Расположение рукояток                      | в верхней части ключа                       |
| Назначение                                 | открывание/закрывание клапана гидранта      |
| Число оборотов полного открытия гидранта   | 10–14                                       |
| Крутящий момент на рукоятке (без давления) | не более 20 Н·м                             |
| Масса отдельного ключа                     | не более 2,1–2,5 кг                         |
# Предназначение

1. ***Открывание и закрывание клапана подземного гидранта.*** Квадратная головка ключа входит в квадратный торец штока гидранта. При установке колонки на гидрант её навинчивают вращением корпуса по часовой стрелке — ключ при этом не поворачивается. Затем при закрытых вентилях колонки ключ вращают против часовой стрелки: за 10–14 оборотов клапан гидранта полностью открывается, и вода из сети поступает в полость колонки. Закрывание — обратным вращением. 
2. ***Регулирование напора.*** Частичным открытием клапана гидранта можно ограничивать подачу воды в колонку. 

*\*важный нюанс: при работе с колонкой на гидранте сначала полностью открывают клапан гидранта ключом, а уже затем открывают вентили колонки — иначе возможен гидроудар и повреждение запорной арматуры.
