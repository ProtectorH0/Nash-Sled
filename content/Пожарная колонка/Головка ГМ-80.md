# Общие сведения

Пожарная колонка (КП) по ГОСТ Р 53250‑2009 — устройство для отбора воды из подземного гидранта при пожаротушении; монтируется на гидрант посредством резьбового соединения (резьба 6″, база 190 мм), оснащена центральным ключом для открытия клапана гидранта и двумя выходными патрубками с вентилями и соединительными головками

# ТТХ

- Условный проход входного патрубка: 125 мм;
- Условный проход напорных патрубков: 80 мм (2 шт.);
- Рабочее давление: 1,0 МПа;
- Габариты: макс. высота 1090 мм, ширина 430 мм;
- Присоединительная резьба основания: 6″;
- Масса: ≤16 кг (для исполнения из алюминиевого сплава)
# Предназначения

- Отвод воды из КП в пожарные рукавные линии;
- Подключение двух рукавных линий одновременно (независимая регулировка подачи вентилями);
- Герметичное соединение с напорными рукавами через муфтовую головку ГМ‑80 (внутренняя резьба для навинчивания на патрубок рукава)
