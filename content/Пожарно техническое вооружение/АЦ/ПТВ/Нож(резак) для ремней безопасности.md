# ТТХ
Согласно ГОСТ Р 22.9.38-2024, резаки для ремней безопасности должны соответствовать следующим требованиям:

- **Конструкция.** Состоят из рукоятки и режущей части (лезвия). Могут быть укомплектованы чехлами (ножнами), которые предохраняют лезвие и человека от повреждений при хранении и транспортировке. 
- **Заточка лезвия.** Должна быть острой, может быть односторонней или двусторонней. Угол заточки — от 30° до 50°. 
- **Толщина лезвия.** От 0,7 до 1,5 мм. 
- **Твёрдость лезвия.** Не менее 49 HRC по ГОСТ 9013. 
- **Качество поверхности.** На металлическом лезвии не допускаются вмятины, трещины, риски, волосовины, рябизна и другие поверхностные дефекты по ГОСТ 21014, а также следы коррозии. На лезвии из керамических и композиционных материалов не допускаются выкрашивания, заусенцы, раковины, трещины, расслоения и другие дефекты, ухудшающие прочность. 
- **Рукоятка.** Если она изготовлена из полимерных материалов, на ней не допускаются трещины, сколы, вздутия, раковины и другие поверхностные дефекты по ГОСТ 24105. 
- **Стойкость к внешним воздействиям.** Рабочие параметры эксплуатации — температура воздуха от −30 °C до +40 °C. Металлические поверхности резака, включая лезвие, должны подвергаться временной противокоррозионной защите в соответствии с требованиями ГОСТ 9.014 для группы изделий И по варианту ВЗ-4.

# Описание
Нож (резак) для ремней безопасности — это инструмент, входящий в пожарно-техническое вооружение (ПТВ), предназначенный для разрезания ремней безопасности в аварийных транспортных средствах при проведении аварийно-спасательных работ, связанных с дорожно-транспортными происшествиями, в том числе при извлечении пострадавших.
___
# ОТ
При использовании резака для ремней безопасности необходимо соблюдать следующие меры безопасности:

- Использовать инструмент только по назначению — для разрезания ремней безопасности. Не применять для работы с другими материалами или в неподходящих условиях.
- Проверять состояние инструмента перед использованием: лезвие должно быть острым, без дефектов, рукоятка — целой.
- Избегать контакта лезвия с кожей и другими частями тела во избежание порезов.
- Использовать средства индивидуальной защиты (например, перчатки), если это предусмотрено инструкциями по охране труда.
- Учитывать особенности конструкции автомобиля: системы преднатяжения ремней и усилители для монтажа ремней безопасности могут повредить резак. 
- Перед резкой проверять опорные основания и стойки, чтобы избежать повреждения скрытых элементов (например, газовых цилиндров систем подушек безопасности).
